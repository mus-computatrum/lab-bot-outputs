# lab-bot-outputs

This repo collects the per-job outputs of the lab's Discord-driven
research bot. Each run lands as `runs/<UTC-timestamp>_<job-id>/` with:

- `README.md` — the per-run request + summary + links
- `notebook.ipynb` — stitched code cells + outputs in Jupyter form
- `code/`, `figures/`, `tables/`, `pdfs/` — categorised artifacts

The bot is at <https://github.com/imbush/discord-claude-bot>.
